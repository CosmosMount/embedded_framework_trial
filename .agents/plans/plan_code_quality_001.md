原因及修改：DMIMU 原在解码时打时间戳，积压帧会被误判为新输入；队列改存接收 tick，分帧组装以最旧部分计时并拒绝过期混组，失联保留递增序号，AHRS 不发布过期完整读数为在线。16 槽目标队列每槽新增 4 字节，共增加 64 字节 RAM，这是保留真实新鲜度所需状态，不声称净节省空间。DM motor 的配置支持超过 255 个槽位，但注册和分发使用 uint8_t 截断；改为 uint16_t，启用等待超时明确返回 timeout。LK 组帧 scratch 从成员改为单次调用的 8 字节局部数组，删除重复 ID 范围检查；每条总线减少 8 字节常驻成员。VT03 按手册检查通道/模式/鼠标按钮范围，删除将非法模式静默映射为 low 的函数。参数生成集中验证 JSON 数字类型与 unsigned 位宽，DMIMU 时间间隔限制为有界 tick 并复用现有生成函数。
